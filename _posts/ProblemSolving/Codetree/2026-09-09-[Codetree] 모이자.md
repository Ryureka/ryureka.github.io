## 풀이 구현
~~~ java
import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }

        int min = Integer.MAX_VALUE;
        for(int i = 0; i < n; i++) {
            int sum = 0;
            for(int j = 0; j < n; j++) {
                sum += a[j]*Math.abs(j-i);
            }
            min = Math.min(min, sum);
        }

        System.out.println(min);
    }
}
~~~
a[j]로 해야하는데 a[i]로 잘못했고 min을 max로 반대로 코딩하는 실수를 했다.
